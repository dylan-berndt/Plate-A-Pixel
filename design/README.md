# UI mockup

`ui-mockup.html` is the exported "Plate-a-Pixel Studio" design canvas
draft - a rough visual pass at the app's screens (canvas view, tool
rail, palette rail, mesh settings), not implemented UI. It's a self-
contained page: open it directly in a browser to view it.

It's a draft, not a spec - `ARCHITECTURE.md` at the repo root is the
authoritative description of the domain/tool/controller layers this UI
should be built against. Treat layout, wording, and control choices
here as a starting point to diverge from where the real controller
layer (see `utils/controllers/`) suggests something different.
